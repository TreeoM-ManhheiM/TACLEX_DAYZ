# Installation Guide

For dedicated DayZ server admins only.

## Requirements

- Windows Server (or Windows 10/11)
- DayZ Server 1.30+ installed via SteamCMD
- DayZ Tools (for repacking the PBO if needed)
- Python 3.11+ (only if running bridge from source)
- Optional: Groq API key
